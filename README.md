# Currency-Converter
A sleek, responsive currency converter web application built with plain HTML, CSS, and JavaScript for seamless currency calculations.

💱 Currency Converter
A simple, fast, and responsive currency converter web application built using vanilla HTML, CSS, and JavaScript.

✨ Features
Accurate Conversions: Quickly convert amounts between various international currencies.

Instant Swapping: Easily swap "From" and "To" currencies with a single click.

Mobile-Friendly: Clean and responsive design that looks great on any device.

🛠️ Tech Stack
HTML5

CSS3

JavaScript (ES6+)

🚀 How to Run
Clone or download this repository.

Open index.html in your web browser.
